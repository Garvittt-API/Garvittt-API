<h2 align="center">💻 System</h2>

I'm a cybersecurity student who spends most of the day in a terminal. I break
systems to learn how they survive, then build the bots and tools that hold up
when they're pointed at real people.

- 🔐 **Offensive security** — web app testing, recon, and writing up every box I root.
- 🤖 **Bot engineering** — Discord APIs, rewrites, sharding, and keeping things online at 3am.
- ⚡ **Small, fast tools** — a CLI or a page that does one thing well beats a platform that does none.
