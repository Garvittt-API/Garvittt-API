## 🧩 About Me

```ts
const garvit = {
  role:      "Cybersecurity student",
  location:  "India  ·  IST (UTC+5:30)",
  builds:    ["Discord bots", "Security tooling", "Developer utilities"],
  stack:     ["Python", "TypeScript", "Go", "Rust", "Flutter"],
  currently: "Val-X, ScamLens, and whatever broke at 2am",
  contact:   "garvitchoudhary2315@gmail.com",
} as const;
```

I'm **Garvit** — a cybersecurity student who got curious about how things break, and stayed for how to build them properly.

Most of what I ship starts as a small annoyance: a bot that keeps timing out, a scan report nobody can read, a music player that lags. So I rebuild it the way I think it should work — small, fast, and explainable. **30 public repos** later, that habit turned into a toolbelt: Discord automation, appsec scanners, semantic search, and a Rust music player that opens faster than you can blink.

- 🔐 **Security-first** — I audit what I build, not just what I test
- 🤖 **Automation-obsessed** — if it's repetitive, it deserves a script
- 🧠 **Logic-driven** — clean architecture beats clever one-liners
- 🌱 **Currently learning** — Rust internals, systems design, shipping faster

> ⚡ **Fun fact:** I genuinely speak to APIs more than I speak to humans.
