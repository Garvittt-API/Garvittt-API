# 🛠️ README-SETUP

Notes for future-you. The profile page is `README.md`; everything visual is either
hand-written SVG in `assets/` or a public badge service.

## The palette (change it in one place)

| Token | Hex | Used for |
| :-- | :-- | :-- |
| background | `05080D` | every card `bg_color` / `labelColor` |
| mint | `00E5A0` | primary accent, titles, rings |
| cyan | `22D3EE` | secondary accent, icons, values |
| text | `E9F7F3` | body text on dark cards |
| muted | `7E93A3` | dates, dim labels |

Every badge passes `labelColor=05080D` and one of the two accents — that single
rule is what makes the page look designed instead of assembled.

## Assets

| File | What it is |
| :-- | :-- |
| `banner-{dark,light}.svg` | hero: glitch name, drifting glows, shield, status pill |
| `terminal.svg` | macOS terminal that types out the spec sheet |
| `bot-{dark,light}.svg` | pixel bot companion (blinks + floats) |
| `marquee-{dark,light}.svg` | infinite two-row stack scroller |
| `divider-{dark,light}.svg` | animated section rule |

All are plain SVG with CSS/SMIL animations — no build step, no external service.
`prefers-reduced-motion` is respected, and dark/light variants are swapped with
`<picture>` + `prefers-color-scheme`.

## The snake

It renders once the workflow has published to the `output` branch:

> **Actions → 🐍 Contribution Snake → Run workflow**

It then refreshes itself every 12 hours. If the image is missing, that workflow
has not run yet.

## Re-skinning the art

The SVGs are generated by a small Python script that lives outside this repo. To
edit by hand, every colour is a literal hex inside each file — a find/replace of
`00E5A0` and `22D3EE` re-themes the whole set.
